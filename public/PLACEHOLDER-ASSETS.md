# Assets to add before launch

This folder intentionally does not include binary placeholder assets.
Add the following before deploying:

- `favicon.ico` — site favicon (referenced in src/app/layout.tsx)
- `og-image.png` — 1200x630 social preview image (referenced in layout.tsx metadata)
- `OxyLoan-Whitepaper.pdf` — linked from the Whitepaper page's "Download PDF" button

You can delete this file once real assets are in place.
